# Data dictionary — `healthcare.cliniq_v5_stage`

All tables are synthetic demonstration data (`is_synthetic = true` on every clinical row). Generated by `datagen/`, ingested by `pipeline/cliniq_pipeline.py` (run as the Databricks notebook `notebooks/ClinIQ_Nexus_10_v5_Ingestion.py`).

Raw files live in the managed volume `healthcare.cliniq_v5_stage.raw` under `v5/` (`fhir/*.ndjson`, `documents/*.pdf`, `dicom/*.dcm`, `manifest.json`).
